# NEXORA — Linux Security Lab

**Author:** Yassin Baklouti
**Date:** November 2026
**Project type:** Linux Administration & Cybersecurity
**Status:** Technical implementation completed

## Project overview

NEXORA is a simulated corporate Linux environment designed to demonstrate fundamental system administration and cybersecurity skills.

## Technologies

- Oracle VirtualBox
- Ubuntu 20.04
- Linux Terminal

## Implementation

- Corporate directory structure
- User and group management
- File ownership and permissions
- Departmental access control
- Backup management
- Disaster recovery
- Network interface analysis

## Results

- 4 employee accounts
- 4 departmental groups
- 16/16 departmental access tests passed
- 4 manually verified file backups
- Successful file recovery with restored ownership and permissions

## Security limitations

This project is an educational lab, not a production-ready secured system. Ubuntu 20.04 is outside standard security support.

## Learning objectives

Apply Linux administration and cybersecurity fundamentals through practical implementation, testing and troubleshooting.
